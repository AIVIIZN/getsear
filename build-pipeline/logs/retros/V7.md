## What worked

- **Custom Postgres logger via plain JSON to stdout.** No pino/winston. Just structured lines. Future log shipper can be Sentry / BetterStack / Logflare without code changes.
- **Web-vitals capture pipeline** with `sendBeacon` → fetch keepalive fallback. Survives page unload. Auth-bypassed via PUBLIC_ROUTES.
- **Tag-based cache invalidation** with org_id-scoped tags. Cross-tenant cache hits structurally impossible.
- **Lazy-loaded reports** dropped 370KB+ off each report page's chunk graph.
- **AVIF/WebP image format negotiation** — Next 16 handles content-type negotiation; clients on modern browsers get AVIF without code changes.

## What hurt / what to fix next time

- **DB drift in V7.2.1**: I (main session) ad-hoc applied a migration via MCP `apply_migration` with a SQL string DIFFERENT from what was in the migration file (the agent's report had a phantom `ticket_id` column that didn't actually exist on `kds_ticket_events`). When I caught it, I aligned by re-applying the file's correct version, but my one-off CREATE INDEX statements remain in the DB without a migration trail. **Fix:** future integrate phase should READ the file and apply it verbatim, not paraphrase from the agent's summary.
- **Logger stub conflict** between V7.1.2 and V7.1.3 worktrees. Both created `src/lib/observability/logger.ts` with different shapes. Resolved at integrate via `git checkout --ours` to keep V7.1.2's canonical version. **Fix:** when dispatching parallel work that touches a new shared module, build the contract first in a 0-task pre-flight commit, then both branches consume it.
- **DEPLOY.sh smoke false-negative** for the V6.3 deploy. Local network blip caused `000000`. The 5.99.8 cycle-2 rollback verification logic correctly prevented overwriting prod (rollback SSH timed out → distinct status). Prod state was actually fine the whole time. **Fix:** consider running smoke from the VM itself or a Cloudflare worker rather than from local Mac.
