- **Synthetic batch 5.99** — 8 specialists in parallel worktrees, ~26 P0s closed in one execution cycle (with cycle-2 fixes for half). The orchestrator pattern executed inline from main session worked even when sub-agent dispatch failed.

## What hurt

- **DEPLOY.sh smoke false-negative** for 6.3 — local-network blip caused `000000`, then SSH timed out for rollback. New 5.99.8 cycle-2 logic correctly distinguished `smoke_failed_rollback_failed`, but the ergonomic UX is still that a working deploy looks failed. Possible V7 follow-up: smoke from the VM itself instead of local Mac.
- **Worktree naming mismatch** — Agent tool produces `agent-*` worktrees, INTEGRATE.sh greps for `v*`. Manual merge needed for every batch. Defer renaming for now.
- **Sub-agent Agent-tool unavailability** — orchestrator pattern broke on 5.99 first attempt. Inline orchestration from main session was the unblock.
